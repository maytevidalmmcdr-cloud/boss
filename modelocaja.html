MODELO DE CAJA

REGRESAR

1. Teoría básica

El modelo de caja es la forma en que CSS considera cada elemento HTML como una caja. Cada caja está formada por cuatro partes: contenido, padding, border y margin.

El contenido es la información que se encuentra dentro del elemento. El padding es el espacio entre el contenido y el borde. El border es el borde que rodea al elemento y el margin es el espacio que existe fuera del borde.
